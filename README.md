
# 👟 FashionVision — Fashion Image Classification

A modern, responsive fashion-themed web application built with **React, Vite, JavaScript, and CSS**, inspired by a deep learning project using the **Fashion-MNIST dataset**.

FashionVision combines a clean, visually engaging interface with the concepts of AI-powered fashion image recognition.

## Project Overview

FashionVision explores the intersection of modern frontend development and machine learning.

The project focuses on presenting fashion classification concepts through a responsive website, with a visual design inspired by contemporary fashion and technology platforms.

The associated machine learning project uses Fashion-MNIST to explore image classification with two approaches:

- Dense Neural Network (DNN)
- Convolutional Neural Network (CNN)

## 🧠 Machine Learning Overview

The Fashion-MNIST dataset contains 70,000 grayscale images across 10 clothing categories.

- Training images: 60,000
- Test images: 10,000
- Image resolution: 28 × 28 pixels
- Number of classes: 10

### Model Comparison

**Dense Neural Network (DNN)**

A baseline neural network for learning relationships between image pixels and clothing classes.

**Convolutional Neural Network (CNN)**

A deep learning model designed to extract spatial patterns from images, making it well suited for visual classification tasks.

The goal is to compare how these architectures perform on the same classification dataset.

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yonduvee/fashionvision-webapp.git
```

### 2. Navigate to the Project

```bash
cd fashionvision-webapp
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, typically:

```text
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

## Design Approach
